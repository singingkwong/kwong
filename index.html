各地市场动态

REGIONAL

中国市场

📊 关键数据 / 事件8月中国汽车产销量分别达251.2万辆、248.5万辆，新能源渗透率43.1%，同比提升6.8pct。
🔍 影响分析内饰轻量化需求带动微发泡注塑设备订单增长45%，本土塑机企业国内市占率提升至78%。
📈 趋势判断Q4新能源车企集中扩产，4000T以上大型两板机供需缺口将达200台。
📌 数据来源：中汽协

东南亚市场

📊 关键数据 / 事件2026年1-8月东南亚新能源汽车销量同比增长128%，中资车企市占率达57%。
🔍 影响分析本地组装产能扩张带动中小型注塑机需求增长，8月中国对东南亚塑机出口同比增长82%。
📈 趋势判断2027年东南亚汽车注塑设备市场规模将突破22亿美元，中国设备市占率有望达60%。
📌 数据来源：MarkLines

南美市场

📊 关键数据 / 事件墨西哥汽车产量1-8月同比增长18%，巴西新能源汽车销量同比增长97%。
🔍 影响分析特斯拉墨西哥工厂、比亚迪巴西工厂扩产带动大型注塑机需求超200台。
📈 趋势判断Q4南美塑机进口额将突破8亿美元，中国设备性价比优势显著。
📌 数据来源：巴西汽车工业协会ANIA

欧洲市场

📊 关键数据 / 事件欧盟正式通过《可持续汽车材料法规》，2030年车用塑料可回收占比不低于30%。
🔍 影响分析生物基塑料注塑工艺需求爆发，多组分注塑机、微发泡注塑机订单同比增长72%。
📈 趋势判断2027年欧洲汽车注塑设备市场规模将突破120亿欧元，环保型设备占比超60%。
📌 数据来源：ACEA欧洲汽车工业协会

北美市场

📊 关键数据 / 事件8月美国新能源汽车销量18.7万辆，同比增长27%，IRA补贴覆盖车型占比提升至62%。
🔍 影响分析本土车企扩产带动保险杠、电池包壳体注塑订单增长，大型注塑机需求环比增长32%。
📈 趋势判断Q4北美塑机缺口预计达120台，中国产高性价比设备渗透率将提升至18%。
📌 数据来源：NADA美国汽车经销商协会

🔍 影响分析塔塔、马恒达等本土车企扩产带动经济型注塑机需求增长，中国对印塑机出口同比增长68%。

📈 趋势判断2027年俄罗斯汽车注塑设备进口额将突破7亿美元，中国设备市占率有望超80%。

🔍 影响分析配套供应链建设带动注塑设备需求增长，8月中国对澳塑机出口同比增长53%。
📈 趋势判断2027年澳洲汽车注塑设备市场规模将突破5亿美元，轻量化设备需求占比提升。

政策动态

POLICY

中国：新能源汽车出口退税新政落地

📊 关键数据 / 事件9月7日财政部发布通知，新能源汽车及配套零部件出口退税率提升至17%，自2026年10月1日起实施。
🔍 影响分析汽车零部件出口成本下降，注塑件出口利润提升约3pct，带动塑机需求增长。
📈 趋势判断Q4汽车注塑件出口同比预计增长25%，海外订单占比将提升至32%。
📌 数据来源：财政部

欧盟：CBAM碳边境税正式实施

📊 关键数据 / 事件9月1日起欧盟CBAM政策正式覆盖汽车零部件，碳排放量超过阈值的产品需缴纳额外关税。
🔍 影响分析低碳注塑工艺、可回收材料需求增长，节能型注塑机出口欧盟的竞争力提升。
📈 趋势判断2027年中国对欧出口节能型注塑机占比将提升至70%，高能耗设备出口受限。
📌 数据来源：欧盟委员会
